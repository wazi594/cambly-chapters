# 子页面阅读系统与背景性能改版设计

## 目标

统一 Cambly 回忆录所有保留子页面的视觉语言，降低标题与导航的压迫感，提高正文、引用和英文对话的可读性；删除四个旧占位页面与文章切换导航；同时降低首页 WebGL 背景的渲染负载和鼠标扰动强度，使流动更舒缓。

## 页面范围

保留并统一使用阅读模板的页面：

- `/stories`：我与老师们的故事
- `/repeated-words`：反复说的话
- `/family-traces`：家人的痕迹
- `/letter`：给 Lou 的一封信
- `/time-capsule`：时间胶囊

保留独立模板：

- `/trajectory`：八十六节课的轨迹。该页面继续承载真实的 `trajectory_report.html`，不与旧的“学习轨迹”占位页混淆。

删除页面与路由：

- `/journey`：学习轨迹
- `/dialogues`：对话记录
- `/growth`：我的成长
- `/notes`：零散记录

删除后的路由不再出现在路由树、内容注册表、文章顺序、元数据或任何站内链接中。

## 统一子页面结构

### 顶部栏

顶部栏由当前 64px 的工具栏改为约 48px 的轻量导航。只保留：

- 左侧“返回首页”链接；
- 桌面端居中的当前文章标题；
- 底部 1px 阅读进度线。

删除 `Memoir H1`、Archive 编号、阅读百分比文本、字号控制、行距控制和 `Index ↑`。顶部栏使用高不透明度纸色背景，不使用大面积 `backdrop-filter`，减少滚动合成开销。

### 文章头部

- 页面编号缩小为约 20px，只作为弱提示。
- 主标题移动端约 38px，桌面端约 56px，行高约 1.08；长标题最多自然换成两行。
- 副标题保持约 15px，提升对比度。
- 删除 `PERSONAL ARCHIVE / LANGUAGE / MEMORY / GROWTH` 等无内容价值的小字。
- 头部最大宽度与正文体系对齐，减少当前标题与右侧信息之间过大的视觉落差。

### 正文与层级

- 正文固定为约 17px，行高约 1.95，不再支持用户调整。
- 正文列宽约 720px；段落间距、章节间距和分隔线在所有保留页面中一致。
- 二级标题约 28–32px，避免相对单位随阅读偏好放大。
- Meta 信息最小不低于 11–12px，并提高颜色对比度。
- 英文对话正文使用新的英文衬线字体，中文释义继续使用中文无衬线字体。

### 引用设计

新增 `Newsreader` 英文衬线字体，作为引用和英文对话的首选字体，中文回退到 `Noto Serif SC`。引用块统一为：

- 上下细线与充足留白；
- 引用正文移动端约 24px、桌面端约 30px；
- 克制的蓝色引号或标记，不再使用过粗的左侧竖线；
- 来源文字约 12px，保证可读但不抢正文。

### 页面底部

删除桌面端上一篇/下一篇双栏索引和移动端固定文章切换栏。文章结尾只保留一个低存在感的“返回首页”链接，不引入新的全站目录。

## 背景性能与交互

现状根因：WebGL 背景在 1280×720 CSS 视口上创建约 2048×1152 的绘制缓冲区，并以每秒约 60 帧执行多次五层 FBM 噪声；鼠标移动时还会持续创建临时向量并放大速度扰动。这是页面卡顿与视觉过于敏感的主要来源。

改版策略：

- 将设备像素比上限由 1.6 降至 1.25；
- 将 FBM 从五层降至四层，并降低高频纹理混合强度；
- 将渲染节流为最高约 30fps；标签页不可见时停止绘制，恢复可见后继续；
- 鼠标事件复用向量，避免每次移动分配对象；
- 鼠标跟随插值由 0.07 降至约 0.025，拖尾插值由 0.02 降至约 0.008；
- 将速度放大、推力、亮度扰动和拖尾影响整体降低约一半；
- `prefers-reduced-motion` 下保持静态画面，不运行连续动画。

视觉结果应是缓慢呼吸、轻微跟随，而不是鼠标附近快速翻涌。

## 代码清理

- `MemoirPage` 删除不再使用的 `next` 字段。
- 删除 `prevOf`、旧页面内容对象与旧 `entries` 列表。
- 删除 `ReadingControls` 和 `useReadingPrefs`，若无其他引用则移除文件。
- 路由树由 TanStack Router 在构建/开发流程中重新生成，确保四条旧路由不存在。
- 保留背景音乐根级组件，确保本次路由清理不影响连续播放。
- 只修复本次涉及源文件的格式问题；不对无关 UI 组件进行大范围机械改写。

## 错误与性能检查

实施前后分别检查：

- 所有保留页面返回 200，四个删除页面返回 404；
- 首页不存在指向四个删除页面的链接或文字目录；
- 子页面不存在字号、行距、上一篇、下一篇控件；
- 五个阅读页使用相同的标题、正文、引用和顶栏结构；
- `/trajectory` 仍能加载真实 HTML 报告；
- 音乐在首页与保留子页面间切换时继续播放；
- 浏览器控制台无运行时错误；
- 桌面与移动端均无横向溢出；
- `prefers-reduced-motion` 得到尊重；
- 自动化测试与生产构建通过。

## 非目标

- 不重写现有 Markdown/HTML 正文内容。
- 不改变首页四屏的主要布局和入口关系。
- 不重新设计 `/trajectory` 报告内部的 HTML 内容。
- 不发布或部署网站，除非用户另行要求。
